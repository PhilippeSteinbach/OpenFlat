# Implementation Plan: Cleaning Board Redesign (Kanban → Checklist)

**Branch**: `001-openflat-foundation` | **Date**: 2026-03-09 | **Spec**: [spec.md](spec.md)
**Input**: User request to transform the Cleaning Board from a Kanban board into a checklist (like Shopping List), showing responsible person, days remaining, and days overdue.

## Summary

Replace the 4-column Kanban drag-and-drop Cleaning Board with a **checklist UI** similar to the Shopping List. Each cleaning item shows the **responsible person's name**, a **days-remaining badge** (green/yellow), or a **days-overdue badge** (red). Tasks are toggled done/undone with a checkbox instead of being dragged between columns. Points and leaderboard gamification are retained.
